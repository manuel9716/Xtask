🌐 API esperada para Recursos Humanos

Método	Ruta	Descripción
GET	/api/recursos-humanos/empleados	Listar empleados
POST	/api/recursos-humanos/empleados	Crear empleado
PATCH	/api/recursos-humanos/empleados/:id	Actualizar empleado
DELETE	/api/recursos-humanos/empleados/:id	Eliminar (desactivar) empleado
GET	/api/recursos-humanos/evaluaciones	Listar evaluaciones
POST	/api/recursos-humanos/evaluaciones	Crear evaluación
GET	/api/recursos-humanos/capacitaciones	Listar capacitaciones
POST	/api/recursos-humanos/capacitaciones	Crear capacitación
POST	/api/recursos-humanos/asistencias	Registrar asistencia a capacitación
