Formulario con campos:

email o username

password

Botón Iniciar sesión

Validación básica antes de enviar (formato, no vacío)

2. Lógica de autenticación
Verificar si el usuario existe (users.username o users.email)

Verificar si la contraseña coincide (hasheada con bcrypt o similar)

Si es correcto, devolver:

Un token de sesión (JWT o session cookie)

Datos del usuario (nombre, rol, id)

Prevención de ataques por fuerza bruta (opcional: throttling)

Manejo de errores claros (credenciales incorrectas, usuario inactivo, etc.)
