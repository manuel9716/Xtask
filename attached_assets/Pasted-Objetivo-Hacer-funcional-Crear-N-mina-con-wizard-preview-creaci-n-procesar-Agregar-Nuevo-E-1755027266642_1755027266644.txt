3) Esquema de datos (usar/migrar)
empleados(id, user_id, nombre, apellido, identificacion UNIQUE, depto, cargo, fecha_ingreso, estado_contrato, tipo_contrato, telefono, direccion, contacto_emergencia, created_at)

4) Endpoints requeridos
Empleados

POST /api/empleados (transacción: empleado + empleado_nomina + empleado_proyecto)

POST /api/empleados/:id/contrato (Multer; PDF/DOCX ≤ 5 MB)

GET /api/empleados?proyectoId?&q? (para selects)

GET /api/proyectos y GET /api/usuarios?query=

Nómina

POST /api/nominas/preview → calcula items (no persiste)

POST /api/nominas → crea nomina + items; valida no duplicar por (rango_inicio, rango_fin, proyecto_id)

POST /api/nominas/:id/procesar → pagada/parcial + payments_log

GET /api/nominas/:id → detalle

GET /api/nominas/:id/export?format=pdf|xlsx → server-side export
