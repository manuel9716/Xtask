# Archivos Legacy - Estructura Anterior

Esta carpeta contiene la estructura anterior del proyecto antes de la reorganización a arquitectura hexagonal.

## Contenido

- `server/`: Estructura anterior del backend
- `docs/`: Documentación movida a `resources/docs/`
- Archivos sueltos movidos a sus respectivas ubicaciones

## Migración

Todos los archivos han sido migrados a la nueva estructura en `src/` siguiendo los principios de arquitectura hexagonal. Esta carpeta se mantiene como referencia temporal.

**IMPORTANTE**: No utilizar los archivos de esta carpeta para desarrollo nuevo. Usar la nueva estructura en `src/`.
